# 心之語 Heart Whisper v2.13

本版新增「收藏」獨立分頁，並保留 v2.12 以前的所有主要功能。

## v2.13 新增

- 底部導覽新增「收藏」分頁。
- 抽到的單張牌可直接「收藏牌卡」。
- 三卡指引中的三張牌也可個別收藏。
- 收藏分頁分成：
  - 收藏牌卡
  - 收藏句子
- 收藏牌卡可直接取消收藏或存成圖片。
- 原本「紀錄」頁不再塞收藏清單，畫面更簡潔。
- 紀錄頁仍保留「收藏的內容」統計數字。
- 收藏牌卡 ID 會保存到瀏覽器儲存空間，重新整理後仍會保留。

## v2.19.2 字體精修
- 中文標題／療癒句維持繁中明體，但調整為更柔和的 500 字重與字距。
- 英文小標改用 Cormorant Garamond，增加精品感。
- 首頁主句、每日一句、牌卡文字與晚安訊息重新調整字級與行距。
- 手機版底部導覽與小字同步提高可讀性。


## v2.19.3 更新

- 移除療癒頁的 30 秒呼吸流程。
- 移除雨聲、海浪、森林、夜晚蟲鳴等環境音功能。
- 移除 Tone.js 依賴。
- 療癒流程改為：晚安抽卡 → 寫下想放下的事 → 晚安小語。
