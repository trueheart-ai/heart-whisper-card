# 心之語 Heart Whisper — v2.19.5

這個版本以 v2.19.3 為基底，保留原有「今日／抽卡／心情／紀錄／收藏／療癒」功能，並將「療癒」頁的晚安抽卡改成 **37 張完整成品圖卡牌庫**。

## 晚安療癒牌庫

- 共 37 張成品卡圖
- 來源為先前製作完成的 30 張正式晚安療癒卡 + 7 張早期試作卡
- 每張卡都是完整圖卡，文字已經在圖裡，不是背景模板動態換字
- 圖片位於 `assets/goodnight-cards/`
- 檔名從 `goodnight-card-01.png` 到 `goodnight-card-37.png`
- 37 張圖檔皆為不同檔案

## 抽卡邏輯

- 優先抽還沒出現過的晚安卡
- 37 張走完一輪後才重新開始
- 新一輪會避開上一張，降低連續重複
- 最近抽過的晚安卡 ID 會儲存在瀏覽器中

## 療癒頁流程

1. 抽今日晚安卡
2. 顯示完整成品卡
3. 可按「換一張」
4. 寫下想放下的事
5. 顯示晚安小語

## GitHub Pages 上傳

請把以下內容放在 Repository 根目錄：

```text
index.html
xin-zhi-yu.jsx
README.md
assets/
```

不要只上傳 ZIP。請先解壓縮後再上傳所有檔案與資料夾。
