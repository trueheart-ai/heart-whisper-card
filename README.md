# 心之語｜Heart Whisper

> 每天，留一點時間給自己。

**心之語 Heart Whisper** 是一個以手機使用體驗為主的療癒抽卡與心情紀錄 Web App。  
透過每日一句、療癒牌卡、心情書寫、收藏與晚安儀式，陪自己在忙碌的生活裡停一下、整理感受，再慢慢往前走。

目前暫定最終版本：**v2.19.18**

---

## ✨ 主要功能

### 1. 今日

- 顯示當天日期與每日療癒文字
- 8 種心情選擇：開心、平靜、委屈、低落、煩躁、疲憊、想被愛、說不上來
- 依照當下心情提供對應的抽卡建議
- 365 則「今日給自己的話」，依日期固定顯示
- 喜歡的句子可以收藏
- 每日文字可直接存成圖片

### 2. 抽卡

提供兩種抽卡方式：

- **每日一卡**：抽一張牌，閱讀完整療癒訊息
- **三卡指引**：一次抽三張牌，直接呈現三段文字指引
  - 此刻｜我正在經歷什麼
  - 放下｜我需要放下什麼
  - 前行｜接下來可以往哪裡走

目前共有 **81 張一般療癒牌卡**，由 9 個主題牌組組成，每組 9 張。

#### 牌組分類

- 今日療癒
- 愛情關係
- 情緒心事
- 勇氣力量
- 人生蛻變
- 豐盛信念
- 放下釋懷
- 宇宙訊息
- 溫柔守候

另外可選擇 **全部牌組**，從完整 81 張牌中抽取。

#### 抽卡機制

- 同一個牌池還有沒抽過的牌時，會優先抽未出現過的牌
- 一輪抽完後才重新進入重複循環
- 三卡指引同一次抽出的三張牌不會重複
- 最近抽過的牌會保存在瀏覽器中，重新整理頁面後仍會保留防重複記憶
- 已移除「深呼吸／想著最在意的事」等待流程，按下「開始抽卡」後直接翻牌

### 3. 心情

- 選擇當下心情
- 寫下今天想告訴自己的話
- 抽卡後可把最新抽到的牌一起帶入當天紀錄
- 可查看與刪除過去的心情記事

### 4. 紀錄

將日常使用慢慢整理成自己的療癒軌跡：

- 使用天數
- 抽卡數量
- 最常出現的心情
- 收藏內容數量
- 最近反覆出現的牌卡提醒
- 最近心情紀錄

### 5. 收藏

可以分開收藏：

- 喜歡的牌卡
- 喜歡的每日句子

收藏後可再次閱讀，也能將牌卡或句子存成圖片。

### 6. 療癒｜晚安儀式

療癒頁使用 **37 張完整晚安療癒成品卡**，每張都是已經完成插畫與文字排版的完整圖卡，不是背景模板動態換字。

晚安流程：

1. 點擊「抽今日晚安卡」
2. 顯示完整晚安療癒卡
3. 可以按「換一張」
4. 寫下今天想放下的一件事
5. 按下「放下它」
6. 閱讀今晚的晚安小語

晚安卡也有防重複機制：37 張卡會優先走完一輪後再重新開始，並盡量避免連續抽到同一張。

## 💾 資料儲存

目前專案沒有後端帳號系統。

心情紀錄、收藏、最近抽卡紀錄等資料，會使用瀏覽器的 **localStorage** 儲存在使用者自己的裝置中。

因此請注意：

- 不同手機或不同瀏覽器不會自動同步資料
- 清除瀏覽器網站資料後，原本的紀錄也會被清除
- 療癒頁「想放下的事」不會被保存

## 🛠 技術

本專案採用純前端靜態網站方式，可直接部署到 GitHub Pages，不需要 Node.js 打包流程。

- React DOM 18.3.1
- Lucide React
- Babel Standalone
- ES Modules / Import Map

## 🚀 GitHub Pages 部署

### 1. 上傳檔案

請先將下載的 ZIP 解壓縮，然後把以下內容放到 Repository 根目錄：

```text
index.html
xin-zhi-yu.jsx
README.md
assets/
```

**不要直接把 ZIP 上傳到 GitHub Pages 當網站內容。**

### 2. 開啟 GitHub Pages

進入 Repository：

**Settings → Pages**

設定：

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

儲存後等待 GitHub 完成部署即可。

如果 Repository 名稱為 `heart-whisper-card`，GitHub Pages 網址通常會是：

```text
https://trueheart-ai.github.io/heart-whisper-card/
```
